## Supported Scripts
- **Latin** — Full Western / European coverage
- **Vietnamese** — Included in Latin support
- **Arabic** — Dedicated shaping and right-to-left layout

No other scripts are included or supported at this time.

## Font Assignments
| Font | Purpose |
|---|---|
| Lexend | Latin + Vietnamese — all standard interface text |
| Readex Pro | Arabic only — applied where needed |

## Quick Start
1. Clone or download from this original source
2. Open `index.html` in any modern browser
3. No build tools, no dependencies, no subfolders — everything sits in root

## Adding New Pages
1. Create file e.g. `about.html` in same root folder
2. Copy `<head>` section from `index.html` to keep fonts + styles
3. Update navigation links in all `.html` files
4. Any new displayed text falls under CC BY-NC-ND
5. Pages must not remove or obscure original source notices

## Compliance
- WCAG contrast ratios maintained throughout
- Respects `prefers-reduced-motion` system setting
- No **`!important`** overrides in CSS
- No emojis — all indicators use Material Symbols
