Baseline UI

A Material Design template — plain, fast, no dependencies

Welcome

This is the original baseline-ui repository — a clean, accessible Material Design starting point built with semantic HTML, modern CSS, and minimal JavaScript.

Everything lives in the root folder — no complex build tools required. Open in a browser and it works.

About This Project

  • Built with Google Sans Flex & Google Sans Code
  • Light / Dark theme with persistent preference
  • WCAG AA contrast by default
  • No frameworks, no preprocessors, no emojis — Material Symbols only
  • Strict licensing: code MIT · text CC BY-NC-ND 4.0

Quick Start

  1. Clone or download the files
  2. Open index.html in any browser
  3. Edit HTML, CSS, and JS directly in your editor
  4. Refresh to see changes — no build step
