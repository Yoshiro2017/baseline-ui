Baseline UI

A clean, Material Design-based interface built with open web standards

Welcome

Baseline UI is a starting point and reference implementation for building modern websites. It follows Material Design principles, uses variable fonts for typography, and is built entirely with plain HTML, CSS, and JavaScript — no frameworks required.

This repository is the original source for the baseline-ui project. If you obtained this code from somewhere else, the version you are viewing may be outdated or modified.

What's Here

  • Variable Font Playground (VFP) — Experiment with variable font axes in real time using simple inline commands
  • Font Stack — Details on the typefaces used and their supported writing systems: Latin and Vietnamese
  • Guide — How to use, modify, and extend this project properly
  • Source — File structure, licenses, and attribution
  • About — Purpose, design philosophy, and project identity

Quick Start

Simply open any .html file in a web browser. All resources load from public CDN links or local files — no build tools needed.

For local development, open this folder in your preferred code editor. JavaScript is separated by feature to keep files short and maintainable.
