Font Stack

Script assignments and usage rules

Supported Scripts

Only three writing systems are officially supported. This keeps the project focused, fast-loading, and high-quality. No other scripts are included or provided.

Script Font Applied How
Latin
English, Filipino, etc.		 Lexend Automatic — no class needed
Vietnamese Lexend Built-in diacritics — fully supported automatically
Arabic Readex Pro Add class="arabic" → applies right-to-left layout automatically
Code / Technical JetBrains Mono Wrap in <code> tag
