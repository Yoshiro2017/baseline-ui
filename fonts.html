Font Stack

Typefaces, variable axes, and supported writing systems

Overview

This project uses variable fonts exclusively for consistent typography with minimal payload size. Two families load on every page; additional families load only on the Variable Font Playground page.

All font resources load directly from Google Fonts via standard `@import` links. No files are hosted locally.

Core Families

Google Sans Flex

Purpose: Primary sans-serif text, headings, UI elements

Axes:

  • opsz — Optical size: 6–144
  • slnt — Slant: −10 to 0 (default 0)
  • wdth — Width: 25–151 (default 100)
  • wght — Weight: 1–1000 (default 400)
  • GRAD — Grade: −50 to 200 (default 0)
  • ROND — Roundness: 0–100 (default 0)

Scripts: Latin, Vietnamese

Google Sans Code

Purpose: Monospace code, snippets, terminal-style text

Axes:

  • wght — Weight: 300–800 (default 400)
  • ital — Italic: 0 or 1 (default 0)
  • MONO — Monospace: 0–1 (default 1)

Scripts: Latin, Vietnamese

VFP-Only Families

These families load exclusively on the Variable Font Playground page and are not used elsewhere on the site:

  • Google Sans — Weight, slant, grade axes; Latin/Vietnamese only
  • Lexend — Weight axis; Latin/Vietnamese
  • Readex Pro — Weight + horizontal expansion (HEXP 0–100, default 0); Latin/Vietnamese
  • Roboto — Weight, width, italic
  • Roboto Mono — Weight, italic
  • Roboto Slab — Weight

No Arabic support is included. Readex Pro is present in the VFP set but serves only Latin and Vietnamese character sets here.

Implementation Notes

All font links use `display=swap` to avoid render-blocking. Preconnect to `fonts.googleapis.com` and `fonts.gstatic.com` is included in `` on every page for faster resolution.

Local fallbacks map to system font stacks so text remains readable before web fonts finish loading.
