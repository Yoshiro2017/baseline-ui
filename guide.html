Usage Guide

How to start, add pages, and stay compliant

Quick Start

  1. Save all files into one folder — no subfolders
  2. Open index.html in any modern browser
  3. That's it — no install, no build tools, no command line

Adding a New Page

Copy index.html, save as new-page.html in the same folder. Update:

  • Page <title> and meta description
  • Main content area — your new material
  • Navigation bar links in all pages so they point to the new file
