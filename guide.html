Guide

How to use, modify, and extend this project correctly

Getting Started

No build tools, package managers, or dependencies are required. You only need a text editor and a web browser.

  1. Copy all files to an empty folder
  2. Open index.html in your browser to preview the site
  3. Edit files in your preferred code editor; save and refresh to see changes

For local preview with proper link behaviour, serve the folder through a basic HTTP server if you encounter cross-origin restrictions.

File Layout

All files sit in the root directory — no subfolders are used.

  • index.html — Home page
  • vfp.html — Variable Font Playground (loads extra fonts and scripts)
  • fonts.html — Typography reference
  • guide.html — This page
  • source.html — Licence, attribution, and file list
  • about.html — Project purpose and identity
  • styles.css — Shared styles across all pages
  • variable.css — Styles specific to the VFP page
  • main.js — Base site behaviour (minimal, extensible)
  • variable.js — VFP parsing and rendering engine

Adding New Pages

To keep consistency, copy the structure from an existing page such as index.html:

  • Include both notice blocks at the very top of <body>
  • Load styles.css and the core font links in <head>
  • Update the bottom navigation bar so every page links to all six destinations
  • Add the new file to the nav list on existing pages
  • Set the correct class="nav-item active" on the current page link

Do not add emoji — use Material Symbols icons instead where needed.

Modifying Styles

Keep all shared base styles in styles.css. If a new feature or page needs unique rules, put them in a separate dedicated CSS file and link it only on that page. This keeps the shared stylesheet lightweight and avoids unintended side effects.

Adjust values in the :root block of styles.css to change colours, spacing, or sizing across the whole site in one go.

Troubleshooting

  • Fonts not loading — check your internet connection; the fonts load from Google Fonts CDN
  • Icons missing — ensure the Material Symbols link is present in <head>
  • JavaScript not running — confirm the <script src="..."> tags point to the correct filenames
  • Page looks unstyled — verify styles.css is in the same folder as the HTML file
