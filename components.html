Components

Ready-to-use building blocks for your interface

Copy, adapt, and drop directly into your pages — no build process required

Overview

Every component below uses classes defined in styles.css. All spacing, colors, and states are consistent with the rest of Baseline UI — they automatically respect light and dark themes, maintain accessibility contrast, and work on both desktop and mobile screens.

No extra tools, no preprocessors, no framework — just plain HTML and CSS. Copy the example code, change the text and link addresses, and drop it into your page.

Buttons

Two button styles are provided: Filled for primary actions and main navigation; Outlined for secondary actions and less prominent links. Use <a> when navigating between pages; use <button> for on-page actions such as closing notices or opening panels.

Filled Button Outlined Button 
<!-- Navigation link — filled style -->
<a href="destination.html" class="btn-filled">Go There</a>

<!-- Navigation link — outlined style -->
<a href="destination.html" class="btn-outlined">Learn More</a>

<!-- On-page action — e.g. close or submit -->
<button class="btn-filled">Submit Form</button>
<button class="btn-outlined">Cancel</button>

Cards

Cards group related information into distinct containers. They provide visual structure and lift slightly when hovered, giving clear feedback. Place icons, headings, paragraphs, and buttons inside as needed.

palette

Example Card

This card shows how content sits together. Icon, heading, text, and action link — all in one consistent block.

Get Started 
<div class="card-filled">
  <span class="material-symbols-outlined icon-lg" style="color: var(--md-sys-color-primary);">palette</span>
  <h3 class="title-lg">Card Heading</h3>
  <p class="body-md">Your description text goes here.</p>
  <a href="page.html" class="btn-filled">Action Label</a>
</div>

Grid Layout

Wrap cards in a .grid container to arrange them side-by-side. On wide screens they appear in columns; on phones they stack automatically so everything remains readable without horizontal scrolling.

<div class="grid">
  <div class="card-filled">…</div>
  <div class="card-filled">…</div>
  <div class="card-filled">…</div>
</div>

Icons

All icons come from Material Symbols — no emojis are used anywhere in this project. Size them with .icon-lg for emphasis or leave at default size. Color them inline using CSS variables to match your theme.

<!-- Standard size -->
<span class="material-symbols-outlined">home</span>

<!-- Larger size -->
<span class="material-symbols-outlined icon-lg">star</span>

<!-- Colored using theme palette -->
<span class="material-symbols-outlined" style="color: var(--md-sys-color-primary);">favorite</span>

Notices & Banners

The source identity notice and license banner at the top of every page are built-in components. The license banner includes a close button that works automatically through main.js — no extra scripting needed.

<!-- Source notice — fixed identity, do not remove -->
<div class="source-notice">
  <span class="material-symbols-outlined">verified_user</span>
  <div><p class="body-md">…text…</p></div>
</div>

<!-- Dismissible notice -->
<div class="license-notice">
  <span class="material-symbols-outlined">info</span>
  <div><p class="body-md">Your message here.</p></div>
  <button class="btn-outlined icon-sm" data-dismiss=".license-notice">
    <span class="material-symbols-outlined">close</span>
  </button>
</div>

Typography Classes

Use these heading and text classes for consistent sizing and weight across every page. Do not use raw <h1>–<h6> without attaching the corresponding class.

Class Usage
.display-md Page titles — largest text on page
.headline-sm Section headings
.title-lg Card and block titles
.body-lg Intro text and emphasized paragraphs
.body-md Standard body text — default everywhere
.label-sm Small labels — navigation, captions
