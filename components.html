Components

Reusable UI elements, markup patterns, and usage examples

Introduction

All components are built with plain HTML and CSS — no frameworks, no extra dependencies. Classes follow a flat naming pattern based on Material Design guidelines. Copy the markup directly into your page and it will render correctly.

Icons use Material Symbols exclusively — do not use emoji in their place.

Implementation Rules

  • Copy, don't re-invent — use the exact class names shown; do not create custom variants unless necessary.
  • Icon sizing — set font-size on the icon span, not via CSS file-level overrides.
  • Active state — always apply class="nav-item active" to the current page link in the bottom nav.
  • Semantic elements — use <button> for actions, <a> for navigation, <nav> for navigation blocks.
  • Code snippets on this page are covered by CC BY-NC-SA 4.0 — share-alike, non-commercial.

Adding New Pages

When adding a new HTML file, update the bottom navigation bar on every existing page so all destinations remain linked. Set the active class on the new page's corresponding nav item.
