Variable Font Playground

Experiment with variable font axes — commands disappear from the final preview

Extra font families loaded here for VFP use only — not loaded elsewhere

How It Works

Type any text into the input box below. Insert commands anywhere — they control how following text appears but vanish completely from preview. Settings persist until overridden or reset with /normal. Unsupported axes are silently ignored.

Command Reference

  • /font [name] — Switch font: Google Sans Flex / Code / Sans / Lexend / Readex Pro / Roboto / Roboto Mono / Roboto Slab
  • /wght [number] — Weight: varies; Readex Pro 160–700
  • /wdth [number] — Width: Flex 25–151, Roboto 75–100
  • /grad [number] — Grade: Flex 0–100, Google Sans −50–200
  • /slnt [number] — Slant: Flex −10 to 0
  • /ital [0 or 1] — Italic: 0 = roman, 1 = italic
  • /rond [number] — Roundness: Flex only, 0–100
  • /hexp [number] — Horizontal expansion: Readex Pro only, default 0, range 0–100
  • /mono [0…1] — Monospace: Code only, 0 = proportional, 1 = fixed
  • /normal — Reset ALL axes to defaults

Example

/wght 400 Hello, /ital 1 /wght 700 world! /normal plain text here

Preview: Hello, (regular) → world! (bold italic) → plain text (defaults)
