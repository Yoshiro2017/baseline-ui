Color System

Material 3 palette — light and dark themes

How It Works

All colors live in :root at the top of styles.css. When you change a value there, it updates automatically across the entire site. The palette switches between light and dark based on your system setting — no toggle needed.

Every combination meets WCAG accessibility standards. Text and background contrast is maintained in both themes.

Palette Reference

Primary

Main brand color — used for buttons, headers, and key actions.

--md-sys-color-primary: #415F91

Secondary

Supporting color — navigation, less prominent elements.

--md-sys-color-secondary: #565F71

Error

Warnings and critical notices.

--md-sys-color-error: #BA1A1A

Surface

Page background and card layers. Several depth levels create visual hierarchy.

--md-sys-color-surface: #F9F9FF
