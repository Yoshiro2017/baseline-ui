Color System

Material 3 palette, CSS variables, and application rules

Palette Philosophy

This project follows the Material 3 colour system with a fixed light-theme baseline. All values are defined as CSS custom properties in styles.css within the :root block — change them once and the entire site updates consistently.

Accessibility is built in: text-on-surface contrast meets WCAG AA minimums by default. Do not lower contrast below these values.

Usage Rules

  • Always reference variables — use var(--md-sys-color-primary) instead of hardcoding hex values. This keeps changes consistent.
  • Layer correctly — place cards and raised elements on Surface Variant or Secondary Container, never pure white.
  • Text hierarchy — headings: On Surface; body: On Surface; secondary/tertiary labels: On Surface Variant.
  • Do not add !important — specificity is kept low so overrides work predictably.
  • Notice backgrounds — Source notice uses light blue tint; Licence notice uses amber tint; these are page-level exceptions and not part of the core palette.

Dark Theme (Planned)

Dark mode is not implemented in this version. When added, it will be done via a media-query or body-class override in styles.css — no new HTML files will be needed.
