Complete File List

All files reside in the root directory — no subfolders are used.

  • index.html — Home / landing page
  • vfp.html — Variable Font Playground (loads extended font set + VFP scripts)
  • fonts.html — Font stack reference and axis documentation
  • guide.html — Usage, modification, and contribution guide
  • source.html — This page
  • about.html — Project identity, philosophy, and acknowledgements
  • styles.css — Shared core styles (all pages)
  • variable.css — VFP page–specific styles
  • main.js — Base site behaviour and shared utilities
  • variable.js — VFP command parser, renderer, and example loader
  • README.md — Project overview and quick-start (CC BY-NC 4.0)
