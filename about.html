About Baseline UI

Purpose, philosophy, and supported languages

Why This Exists

Baseline UI was built to provide a clean, accessible, no-build interface system that works well across multiple languages without unnecessary complexity. No Node.js, no bundlers, no heavy dependencies — just plain files that open in any browser.

It follows Material 3 design principles but keeps the codebase small, flat, and easy to understand or extend.

Supported Languages & Scripts

Only three writing systems are officially supported. Focusing on a small set ensures high typographic quality and fast page loads.

  • Latin — English, Filipino, Spanish, French, and other Western/European languages
  • Vietnamese — Full diacritic coverage built into Lexend
  • Arabic — Correct right-to-left layout and glyph shaping via Readex Pro

Support for additional scripts is not planned at this time.

Design Rules We Follow

  • Zero emojis — all icons use Material Symbols
  • No !important overrides in CSS
  • Respect system settings — dark mode and reduced motion
  • WCAG accessible contrast in both themes
  • Everything in root folder — no confusing structure
